# 料理ログ (Canele Log)

料理の試作（テストクック）を**カテゴリ別に**記録・比較するためのObsidianプラグインです。もともとはカヌレの試作記録用でしたが、カヌレはカテゴリのひとつとして、焼き菓子から煮込み料理まで何でも記録できます。

- サーバー不要、iPhone/iPad/デスクトップのObsidianアプリだけで完結します
- 記録は Vault 内に frontmatter 付きの Markdown ノートとして保存されるため、Obsidian の通常のノートとしてもそのまま閲覧・編集できます
- カテゴリ・材料配合・調理工程（複数段の温度/時間）・評価（★1〜5）・タグ・写真を記録し、カテゴリやタグで絞り込んで一覧・比較ができます

詳細な仕様は [SPEC.md](./SPEC.md) を参照してください。

## 開発

```bash
npm install
npm run dev    # esbuildのwatchビルド
npm run build  # 本番ビルド（型チェック + main.js生成）
```

ビルドした `main.js` / `manifest.json` / `styles.css` を Vault の
`.obsidian/plugins/canele-log/` に配置し、Obsidianの設定からコミュニティプラグインを有効化してください。

## 主な機能

- 試作記録の作成・編集・削除（ノートのファイル名はレシピのタイトル。タイトル変更でファイルも自動リネーム）
- カテゴリ（料理の種類）での分類・絞り込み
- 📷 レシピ画像からの自動入力（任意・Anthropic API キーが必要）— 材料・工程などを推定してフォームに下書き入力し、入力画像は写真にも保存
- 材料配合（可変長）の入力
- 調理工程（可変長）の入力 — 手順ごとに温度・時間を複数記録（温度/時間は任意）
- ノート本文に「写真」「材料」表・「調理工程」リストを自動生成 — 記録を開くだけで画像も中身もすぐ見られる
- 写真の添付（複数枚）— 編集時はサムネイル表示され、読み取り元画像と入力項目を見比べられる（クリックで拡大）
- 5段階評価
- タグ付け・タグ絞り込み
- 既存レシピからの複製
- 複数試作の比較ビュー
- Obsidian「ベース(Bases)」用の frontmatter を完備。同梱の `料理ログ.base` を Vault に置けば、Notion 風のテーブル/ギャラリー表示ができる（カードのカバー画像用に `cover` プロパティを自動付与）

## Bases（テーブル/ギャラリー表示）

Obsidian 1.9+ のコア機能「ベース(Bases)」で、記録を Notion のようにテーブル・ギャラリー表示できます。

1. 設定 → コアプラグインで **Bases** を有効化
2. リポジトリ同梱の **`料理ログ.base`** を Vault 内にコピー（保存先フォルダを既定の `Recipes` から変えている場合は、ファイル内の `file.inFolder("Recipes")` を実際のフォルダ名に変更）
3. その `.base` を開くと **「一覧（テーブル）」**（日付降順）と **「ギャラリー」**（評価順・写真カバー付き）が使えます
4. カテゴリでの絞り込みは各ビューのフィルタUIから。ギャラリーのカバーは各記録の先頭写真（`cover` プロパティ）を使用
5. カバー画像は記録モーダルの写真一覧で、使いたい写真の「カバーにする」ボタンを押すと変更できる（先頭＝カバー）

## 設定

- **記録保存フォルダ** / **添付ファイルフォルダ**（デフォルト: `Recipes` / `Recipes/attachments`）
- **カテゴリ一覧**: 料理の種類をカンマ区切りで登録（記録時の候補に表示）
- **デフォルトカテゴリ**: 新規記録時に最初から選ばれるカテゴリ
- **Anthropic API キー**: 画像読み取り機能を使う場合に設定（任意）。空欄なら機能は無効。キーは Vault 内（`.obsidian`）に平文で保存され、Vault 同期時は他端末にも同期されるため、用途を限定した専用キーを推奨
- **読み取りモデル**: Haiku 4.5（安い・推奨）/ Sonnet 5（バランス）/ Opus 4.8（高精度）から選択

## 画像からの読み取りについて

「Anthropic API キー」を設定すると、記録モーダルに **📷 画像から入力** が表示されます。レシピ写真を選ぶと、Anthropic の画像対応モデルがカテゴリ・材料・調理工程・メモを推定してフォームに**下書き**入力し、同時にその画像を**写真欄にも追加**します。抽出結果は保存前に確認・修正できます。通信は Obsidian の `requestUrl` 経由で Anthropic API に直接送られ、第三者には送信されません。
