# 料理ログ (Canele Log)

料理の試作（テストクック）を**カテゴリ別に**記録・比較するためのObsidianプラグインです。もともとはカヌレの試作記録用でしたが、カヌレはカテゴリのひとつとして、焼き菓子から煮込み料理まで何でも記録できます。

- サーバー不要、iPhone/iPad/デスクトップのObsidianアプリだけで完結します
- 記録は Vault 内に frontmatter 付きの Markdown ノートとして保存されるため、Obsidian の通常のノートとしてもそのまま閲覧・編集できます
- カテゴリ・材料配合・調理工程（複数段の温度/時間）・評価（★1〜5）・タグ・写真を記録し、カテゴリやタグで絞り込んで一覧・比較ができます

詳細な仕様は [SPEC.md](./SPEC.md) を参照してください。

## 開発

```bash
npm install
npm run dev    # esbuildのwatchビルド
npm run build  # 本番ビルド（型チェック + main.js生成）
```

ビルドした `main.js` / `manifest.json` / `styles.css` を Vault の
`.obsidian/plugins/canele-log/` に配置し、Obsidianの設定からコミュニティプラグインを有効化してください。

## 主な機能

- 試作記録の作成・編集・削除
- カテゴリ（料理の種類）での分類・絞り込み
- 材料配合（可変長）の入力
- 調理工程（可変長）の入力 — 手順ごとに温度・時間を複数記録（温度/時間は任意）
- 写真の添付（複数枚）
- 5段階評価
- タグ付け・タグ絞り込み
- 既存レシピからの複製
- 複数試作の比較ビュー

## 設定

- **記録保存フォルダ** / **添付ファイルフォルダ**（デフォルト: `Recipes` / `Recipes/attachments`）
- **カテゴリ一覧**: 料理の種類をカンマ区切りで登録（記録時の候補に表示）
- **デフォルトカテゴリ**: 新規記録時に最初から選ばれるカテゴリ
